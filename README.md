# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房一条权威水位（全局时钟口径选定之钟）+ 允许迟到秒；另一钟仅审计 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 / 口径漂移失败闭 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 |

## 双钟水位线（时钟口径 · 口径账本接管）

口径权威只在**口径账本**，账本接管此后一切抬升与关窗。全局贯彻唯一设计取舍——**强制切换重放**：

- **首次选定同票钉账**：首批事件入流时，同票写入账本（房间、口径、生效水位、账本世代）。禁止选定成功而账本口径空、禁止空白壳世代（核证 `valid=false` 且永不采信）。
- **账本世代锁钟**：水位写闸、关窗扫描、旁路界只吃账本现行世代口径，关窗行盖账本世代戳；改站规字段不换钟（越权直改站规，装载仍按旧世代事件时跑，核证暴露漂移）。
- **强制切换重放**：改钟必须同票——作废旧账本（状态=已作废）→ 按新钟重放未关闭边界（已关闭窗结论冻结、不回溯）→ 写新世代账本并更新站规，整票同成败；禁止只改站规不重放、禁止无新世代却两套钟混出关闭结论。
- **并发整票同成败**：WAL + `BEGIN IMMEDIATE` + `busy_timeout`，改钟与关窗扫描事务在写锁外串行；锁冲突等待或整票回滚重试，全库任一刻只许一套现行钟、一套关闭结论。
- **口径=事件时**（默认）：水位=已见最大事件时；处理时仅审计。**口径=处理时**：水位=已见最大处理时；事件时仅用于窗键对齐，不得反过来抬水位。

每房水位线只有一列权威「水位」+ 口径戳，关窗/旁路只认它；另一只钟进审计列（`审计事件时`/`审计处理时`）。只读接口：

- `GET /api/双钟水位`：房间、水位（按账本口径即事件时或处理时水位）、账本世代、口径、valid。
- `GET /api/核证/口径账本`：账本世代链（现行/已作废）、钉死、现行口径、valid 与硬约束问题（空壳、双钟并存、水位/世代戳漂移、无世代关闭行）。

口径漂移**失败闭**：水位行口径戳与账本现行世代不一致（越权改库造成的切换半截）时，入流对该房失败闭：不抬水位、不关窗、事件落旁路，`valid=false`。系统全空（无事件/窗/撤回/旁路）时 `POST /api/口径` 原子切换（站规+全部水位行口径戳同一事务），无物可重放。

夹具演示：

1. **甲（钉账不漂移）**：推「账本钉账样例」（或「双钟水位样例」）同票钉事件时世代1——钉账样例关闭集={12:00}（双钟水位样例为 {12:00,12:01}）按事件时钉死；此后即使直改站规为处理时，灌入事件仍按旧世代事件时抬升/关窗，关闭集零漂移（测试 `test_禁止只改站规就换钟`）。
2. **乙（重放才换钟）**：推「双钟切换重放样例」（批首带 `尝试切换口径:处理时`，或 `POST /api/口径`）→ 旧世代作废、世代2 按处理时重放：旧关闭窗保持世代1 冻结，未关闭窗按新水位重判并盖世代2；再推「账本改钟重放样例」，新事件只按处理时口径抬升/关窗（L5 入 12:05 窗世代2 关闭，L6 超迟到旁路）。
3. **并发**：「改钟关窗并发样例」与改钟请求同时发起，两票整票同成败，无双套关闭结论并存（线程级测试见 `backend/tests/test_口径账本.py`，含持写锁 2s 下灌流等待后整票成功）。
